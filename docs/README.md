# MuleSoft Properties Manager — Documentation Site

Landing page and documentation for the MuleSoft Properties Manager project.

## Development

Open `index.html` in a browser, or serve with:

```bash
npx serve .
```

## Deployment

Deployed automatically to `mpm.tools.unes.me/docs` via GitHub Pages on push to `main`.

## Structure

- `index.html` — Landing page with features, screenshots, embedded tool, and download links
- `style.css` — GitHub Primer-inspired styling
- `favicon.svg` — App icon
- `screenshots/` — Screenshot images (add your own)
